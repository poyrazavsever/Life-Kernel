# Weekly review

Read the week's daily notes, project sessions, and accepted decisions. Distinguish observed patterns from guesses. Review completed outcomes, stalled work and reasons, energy, capacity, unexpected work, and open loops. Propose no more than a small set of commitments within demonstrated capacity. Preview the weekly review note and any project changes before applying them.
