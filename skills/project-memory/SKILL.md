# Project memory

Use at the end of meaningful project work. Read the project context and search for an existing session with the same external session or request ID. Record only work actually completed, source files or URLs consulted, verification that really ran, decisions accepted by the user, proposals still awaiting a decision, open questions, and one next action. Keep code in the repository; store a concise durable account in the vault. Apply via a routed, idempotent write.
