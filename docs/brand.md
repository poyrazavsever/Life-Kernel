# Life Kernel brand

Life Kernel uses the **Context Route** symbol and the **Quiet Infrastructure** color system. The identity is intentionally light, compact, and calm so it can sit beside technical documentation without overpowering it.

## Brand lock

- **Symbol:** Context Route
- **Display type:** Sora, weight 600
- **Body type:** IBM Plex Sans, weight 400
- **Shape language:** rounded square geometry, one continuous route, one terminal core
- **Primary treatment:** Carbon route with a Route Blue core on Archive Paper

## Palette

| Token | Hex | Role |
| --- | --- | --- |
| Archive Paper | `#F3F0E8` | Primary light background |
| Carbon | `#17191C` | Text and primary mark |
| Route Blue | `#335CFF` | Core accent and interactive emphasis |
| Graphite Mist | `#A7ADB8` | Supporting lines and secondary UI |

Use Archive Paper as the default canvas. Carbon should carry most of the visual weight; Route Blue should remain a small, precise accent.

## Typography

- [Sora](https://fonts.google.com/specimen/Sora) is the display face for product names, headings, and short statements.
- [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) is the body face for documentation and interface copy.

Use `Sora, sans-serif` and `"IBM Plex Sans", sans-serif` as practical CSS stacks. Install or load the Google Fonts files when exact typography matters.

## Logo use

- Preserve the square canvas and the Archive Paper background.
- Leave clear space around the mark equal to at least the width of the blue core.
- Do not redraw, stretch, rotate, add gradients, recolor individual paths, or place effects over the symbol.
- At small sizes, use the symbol by itself. Pair it with the words “Life Kernel” in Sora for larger product surfaces.
